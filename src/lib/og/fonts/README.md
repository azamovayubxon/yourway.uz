# Шрифты картинок «Поделиться»

Статичные TTF из Google Fonts для `next/og` (src/lib/og/share-images.tsx):

- `Commissioner-ExtraBold.ttf` — Commissioner 800 (заголовки);
- `Onest-Regular.ttf`, `Onest-Bold.ttf` — Onest 400 и 700 (текст).

Оба шрифта распространяются по лицензии SIL Open Font License 1.1
(https://openfontlicense.org): их можно свободно использовать, встраивать и распространять.
