# yourway.uz

Платформа профориентации и жизненного планирования для Узбекистана (UZ/RU): психологические тесты и опрос, по которым ИИ составляет персональный маршрут из точки А в точку Б.

- Инструкция для Claude Code: [`CLAUDE.md`](CLAUDE.md)
- План этапов и чек-листы: [`docs/PLAN.md`](docs/PLAN.md)
- Документы продукта: [`docs/`](docs/)
- Тесты и опрос (JSON): [`data/tests/`](data/tests/)

## Стек

Next.js (App Router) + TypeScript, Tailwind CSS, PostgreSQL + Prisma, Vitest. Хостинг: Vercel + Neon.

## Как запустить у себя

Нужны Node.js 22 и PostgreSQL.

```bash
npm install              # установить зависимости (заодно сгенерируется клиент Prisma)
cp .env.example .env     # создать файл настроек и вписать строку подключения к базе
npm run db:deploy        # применить миграции базы (пока их нет — это нормально)
npm run dev              # запустить сайт на http://localhost:3000
```

Проверка, что сайт видит базу: открыть http://localhost:3000/api/health — должно быть `{"ok":true,"db":"ok"}`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт в режиме разработки |
| `npm run build` / `npm start` | сборка и запуск как на боевом сервере (работает на любом хостинге с Node.js) |
| `npm test` | автотесты (Vitest) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run db:migrate` | создать новую миграцию после правки `prisma/schema.prisma` (для разработки) |
| `npm run db:deploy` | применить миграции к базе |

На Vercel сборка идёт через `npm run vercel-build`: генерация клиента Prisma → миграции (`scripts/migrate-deploy.mjs`) → сборка сайта. Пока миграций нет, шаг миграций пропускается и к базе во время сборки не подключается. Если миграции не применились, в логе сборки будут строки `[migrate]` с причиной.

## Где что лежит

| Путь | Что там |
|---|---|
| `src/i18n/dictionaries/uz.ts`, `ru.ts` | **все тексты сайта** на двух языках (лендинг, страницы, футер) |
| `src/app/` | страницы сайта (`page.tsx` в каждой папке = одна страница) |
| `src/components/` | общие части страниц: шапка, футер, переключатель языка, блоки |
| `src/app/globals.css` | фирменные цвета и шрифт |
| `prisma/schema.prisma` | структура базы данных |
| `data/tests/*.json` | вопросы тестов и ключи подсчёта (читаются как есть, узбекские апострофы исправляются при загрузке) |
| `src/lib/assessment/` | загрузка тестов (`tests.ts`), движок подсчёта баллов (`scoring.ts`) и его автотесты |
| `src/app/start/`, `src/app/test/` | экран-развилка и прохождение тестов |
| `src/app/dev/profile/[id]/` | служебная страница с посчитанными баллами (не открывается на боевом сайте) |
| `.env.example` | список всех настроек с пояснениями |

## Прохождение тестов

- `/start` — экран-развилка «знаю цель / не знаю». Выбор создаёт анонимную сессию (её id хранится в cookie `yw_session`).
- `/test` — 4 теста подряд, один вопрос на экран. Каждый ответ сразу сохраняется в базу. Если связи нет, ответы ждут в памяти браузера и отправляются, когда связь появится.
- Когда отвечены все 110 вопросов, сервер считает баллы и сохраняет их в сессии.
- `/dev/profile/<id сессии>` — посчитанные баллы. Открывается локально и на превью-ссылках Vercel, на боевом сайте (`VERCEL_ENV=production`, а вне Vercel — `NODE_ENV=production`) отдаёт 404.

## Языки

Язык хранится в cookie `locale`. Новому посетителю показывается язык из `DEFAULT_LOCALE` (по умолчанию `uz`).
В узбекских текстах буквы `oʻ gʻ` пишутся знаком `ʻ` (U+02BB), апостроф внутри слова (`taʼlim`) — знаком `ʼ` (U+02BC). Автотест проверяет, что в словаре нет обычных апострофов.
