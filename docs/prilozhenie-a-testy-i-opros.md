# Приложение А. Тесты, опрос и сборка профиля (yourway.uz)

**Версия:** 1.0
**Назначение:** единый справочник по всему слою сбора данных — тесты, контекстный опрос, алгоритмы подсчёта и итоговая структура профиля, который передаётся в промпты ИИ (Приложение Б). Часть ТЗ платформы.

## 2. Единый формат и общие правила

Все тесты имеют одинаковую структуру: `meta` / `questions` / `scoring` / `interpretation`.

- Тексты — на двух языках (`text_ru` / `text_uz` или вложенные объекты).
- Служебные ключи и коды (`factor`, `type`, `value`, `style`, `point_to`) — на английском, неизменны.
- Ответы на тесты — по 5-балльной шкале Ликерта (1–5).
- Подсчёт — **детерминированный, на бэкенде, без ИИ** (scoring-движок).
- Язык генерации отчёта берётся из настройки интерфейса, а не из данных теста.

## 3. Тест 1 — Big Five (IPIP-NEO-60)

**Измеряет:** пять черт личности — Нейротизм, Экстраверсию, Открытость, Доброжелательность, Сознательность (30 фасетов).
**Структура:** 60 пунктов, 12 на шкалу (6 прямых + 6 обратных), все 30 фасетов по 2 пункта.
**Шкала ответов:** 1 «совсем не про меня» … 5 «полностью про меня».

**Подсчёт:**
1. Прямой пункт (`is_reverse=false`): балл = ответу.
2. Обратный пункт (`is_reverse=true`): балл = `6 − ответ`.
3. Сумма по каждой шкале (12 пунктов → raw 12–60).
4. Нормализация в проценты (см. раздел 10):
   `pct = round((raw − 12) / 48 × 100)` → 0–100.

**Выход:** `big_five = {neuroticism, extraversion, openness, agreeableness, conscientiousness}` в процентах.

### 3a. Деривация 16-типа из Big Five

Отдельный MBTI-тест не проводится. 4-буквенный тип вычисляется из процентов Big Five (порог 50):

- **E/I** ← Экстраверсия (≥50 → E, иначе I)
- **S/N** ← Открытость (≥50 → N, иначе S)
- **T/F** ← Доброжелательность (≥50 → F, иначе T)
- **J/P** ← Сознательность (≥50 → J, иначе P)

Нейротизм в 4 буквы не входит — используется отдельно (устойчивость к стрессу, темп, риск). Названия 16 типов (ru/uz) — в `bigfive_to_16type_mapping.json`. Тип служит для вовлечения/шеринга, НЕ как научная основа выводов.

**Выход:** `sixteen_type = {code, nickname}` (напр. `{"code":"INFP","nickname":"Идеалист"}`).

## 4. Тест 2 — RIASEC (интересы)

**Измеряет:** профессиональные интересы по модели Холланда — 6 типов: R (реалистичный), I (исследовательский), A (артистичный), S (социальный), E (предприимчивый), C (конвенциональный).
**Структура:** 30 пунктов, по 5 на тип, без обратных. Порядок чередуется (R→I→A→S→E→C) для UX.
**Шкала ответов:** 1 «совсем не интересно» … 5 «очень интересно».

**Подсчёт:**
1. Сумма по каждому из 6 типов (5 пунктов → raw 5–25).
2. Код Холланда = 3 типа с наибольшей суммой, по убыванию (напр. `IAS`).

**Выход:** `riasec = {code, scores}`, где `scores` — суммы по всем 6 типам (для нюансов).

---

## 5. Тест 3 — Ценности / мотивация

**Измеряет:** что для человека значит успех — 6 ценностей: деньги, свобода, стабильность, признание, помощь людям, творчество.
**Структура:** 12 пунктов, по 2 на ценность.
**Шкала ответов:** 1 «совсем не важно» … 5 «очень важно».

**Подсчёт:**
1. Сумма по каждой ценности (2 пункта → raw 2–10).
2. Ранжирование по убыванию суммы.

**Выход:** `values_ranked` — список ценностей от важнейшей к наименее важной.

---

## 6. Тест 4 — Восприятие (стиль обучения)

**Измеряет:** предпочтительный способ обучения — чтение/текст, слушание/лекции, практика/делание, повторение/шаблоны.
**Структура:** 8 пунктов, по 2 на стиль.
**Шкала ответов:** 1 «совсем не про меня» … 5 «полностью про меня».

**Подсчёт:**
1. Сумма по каждому стилю (2 пункта → raw 2–10).
2. Доминирующий стиль = максимальная сумма (при близких значениях — топ-2).

**Выход:** `learning_style` — доминирующий стиль (строка или топ-2).
*Примечание:* «стили обучения» научно дискуссионны; используются как практический совет по формату обучения, не как диагностика.

---

## 7. Контекстный опрос

**Собирает:** демографию, ресурсы (точка А), цель (точка Б). Блок цели — только при `path_type = knows_goal`.

- **Секция «О тебе»:** возраст, пол, статус.
- **Секция «Ресурсы»:** бюджет, часы в неделю, языки, уровень английского, готовность к переезду, готовность к онлайну, уровень опыта, (опц.) навыки, (опц.) интересы.
- **Развилка:** `path_type` (знаю / не знаю цель) — может быть задан на экране до тестов.
- **Секция «Цель»** (условно): формулировка цели, желаемый доход, формат работы, срок, отношение к риску, приоритеты образа жизни.

Каждый ответ через поле `maps_to` пишется в соответствующее поле профиля. Типы вопросов: `single_select`, `multi_select`, `number`, `text`. Условный показ — через `show_if`.

---

## 8. Конвейер подсчёта (pipeline)

```
Сырые ответы (тесты + опрос)
        ↓  [scoring-движок, детерминированно]
Баллы по шкалам (Big Five %, RIASEC-код, values_ranked, learning_style, 16-тип)
        ↓  [сборка]
ПРОФИЛЬ (единый JSON)
        ↓  [подстановка в промпт]
Claude API → тизер / полный отчёт (Приложение Б)
```

Ключевой принцип: **ИИ никогда не считает баллы сам** — он получает уже готовый, посчитанный профиль. Это гарантирует стабильность качества.

## 10. Нормализация и нормы (важно)

Формула `pct = (raw − min) / (max − min) × 100` даёт **процент от максимума шкалы**, а не истинный процентиль относительно популяции. Истинные процентили требуют популяционных норм (распределения баллов по реальным пользователям), которых на старте нет.

**Решение:**
- На старте использовать линейную нормализацию (процент от максимума) — этого достаточно для качественной интерпретации ИИ.
- По мере накопления данных (несколько тысяч прохождений) собрать собственные нормы по Узбекистану и заменить линейную нормализацию на процентильную. Это повысит точность формулировок «выше/ниже среднего».
- Пороги деривации 16-типа (50) при переходе на нормы пересчитать относительно медианы.

## 11. Порядок прохождения в воронке (рекомендация UX)

1. Экран-развилка: `path_type` (знаю / не знаю цель).
2. Big Five (60) — самый длинный, ставим первым, пока внимание свежее; дробить на экраны с прогрессом.
3. RIASEC (30).
4. Ценности (12).
5. Восприятие (8).
6. Контекстный опрос (демография → ресурсы → цель).
7. Генерация → тизер.

Везде — прогресс-бар и автосохранение; при обрыве связи прогресс не теряется.
