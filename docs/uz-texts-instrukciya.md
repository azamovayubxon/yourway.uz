# Как вычитать узбекские тексты и вернуть исправления

В файле [`uz-texts.csv`](uz-texts.csv) собраны **все узбекские тексты сайта**: интерфейс, страницы, заготовка тизера для тестового режима, вопросы опроса и тестов. Около 470 строк.

Тексты, которые пишет ИИ, в таблице не участвуют. Их стиль задают [`uz-style.md`](uz-style.md), [`uz-glossary.md`](uz-glossary.md) и [`uz-teaser-examples.md`](uz-teaser-examples.md).

## Колонки

| Колонка | Что в ней | Что делать |
|---|---|---|
| **ключ** | служебное имя строки (`ui.landing.hero.title`) | не трогать |
| **русский** | тот же текст на русском, для сверки | не трогать |
| **узбекский** | текущий узбекский текст на сайте | не трогать |
| **исправление** | пусто | вписать правильный вариант, **только если текст нужно поменять** |

Если строка нормальная, колонку «исправление» оставьте пустой.

Что означает начало ключа:

- `ui.` — интерфейс сайта (лендинг, кнопки, страницы, тизер). Строки `ui.devProfile.` — служебная страница для разработки, её видят только разработчики; можно пропустить;
- `mock.teaser.` — образец тизера, который показывается в тестовом режиме ИИ;
- `survey.` — вопросы и варианты ответа контекстного опроса;
- `test.` — вопросы четырёх тестов и подписи кнопок 1–5.

Фигурные скобки `{n}`, `{total}`, `{lang}` — места, куда сайт сам подставит число или название языка. Их нужно оставить в исправленном тексте как есть.

Букву oʻ и gʻ можно писать обычным апострофом (`o'`, `g'`): при переносе в код он заменится на правильный знак.

## Как открыть

- **Numbers (Mac):** просто откройте файл двойным щелчком.
- **Excel:** Файл → Открыть → выберите `uz-texts.csv`. Если весь текст оказался в одной колонке или вместо узбекских букв «кракозябры», откройте так: Данные → Из текста/CSV → кодировка **UTF-8**, разделитель **запятая**.

Скачать файл: на GitHub откройте `docs/uz-texts.csv` → кнопка «Download raw file» (стрелка вниз справа сверху).

## Как сохранить

- **Numbers:** Файл → Экспортировать → CSV… → кодировка **Unicode (UTF-8)**.
- **Excel:** Файл → Сохранить как → тип файла **«CSV UTF-8 (разделитель — запятая)»**. Если Excel сохранит с точкой с запятой — ничего страшного, программа поймёт и такой файл.

Имя файла можно оставить `uz-texts.csv`.

## Как отдать мне обратно

Выберите любой способ:

1. **Проще всего:** в новой сессии Claude Code прикрепите исправленный файл и напишите: «Примени исправления из таблицы uz-texts.csv».
2. **Через GitHub:** откройте папку `docs` в репозитории → «Add file» → «Upload files» → перетащите `uz-texts.csv` → внизу выберите «Create a new branch» → «Commit changes». Потом напишите мне: «Примени исправления из docs/uz-texts.csv в ветке …».

Что я сделаю: перенесу каждое исправление в нужное место кода (словари, опрос, тесты, заготовку тизера), прогоню проверки (в том числе проверку на «sen», английские слова и запрещённые конструкции), пересоздам таблицу и пришлю превью-ссылку, чтобы вы посмотрели тексты на сайте.

## Если тексты в коде поменялись

После любых правок текстов таблицу нужно пересоздать командой `npm run uz:export` (это делаю я). Уже вписанные исправления при этом не теряются. Автотест не даст забыть: если таблица отстала от кода, тесты не пройдут.
