# План разработки yourway.uz

Этапы взяты из `CLAUDE.md` (раздел 9). Каждый этап делается в отдельной сессии.
Под каждым этапом есть чек-лист «Как проверить». Его проходит владелец в браузере, без знания кода.

Отметки: `[ ]` не проверено, `[x]` проверено.

---

## Общие условия готовности любого этапа

Эти пункты проверяются в конце **каждого** этапа, помимо его собственного чек-листа.

- [ ] Проект собирается без ошибок (об этом скажет Claude в отчёте; на Vercel превью-ссылка открывается).
- [ ] Автотесты проходят (Claude пишет в отчёте: «тесты: N из N прошли»).
- [ ] Страницы этапа нормально выглядят на телефоне: в браузере на компьютере открыть режим телефона (F12 → значок телефона → ширина 375) или открыть превью-ссылку прямо с телефона. Ничего не вылезает за край, кнопки нажимаются пальцем.
- [ ] Всё переведено: переключить язык UZ ↔ RU, на странице не осталось текста на другом языке и «технических» надписей вроде `landing.title`.
- [ ] Узбекские буквы `oʻ gʻ` отображаются нормально (не квадратиками и не знаками вопроса).
- [ ] Изменения сохранены в репозитории (commit + push), превью-ссылка обновилась.
- [ ] Получен отчёт: что сделано / как проверить / что дальше.

## Этап 1. Каркас

**Что появится:** пустой, но настоящий сайт: лендинг, статические страницы, переключатель языка, база данных подключена.

**Как проверить:**
- [ ] Открыть главную страницу: видны блоки лендинга (главный посыл, кнопка «Начать бесплатно», как это работает, пример отчёта, отзывы, цены, FAQ, футер).
- [ ] Тексты на лендинге выглядят как заглушки, и в отчёте Claude указано, в каком файле их менять.
- [ ] Переключатель UZ/RU есть вверху на каждой странице.
- [ ] Переключить язык на RU, перезагрузить страницу: язык остался RU.
- [ ] Открыть сайт в новом «инкогнито»-окне: язык по умолчанию узбекский.
- [ ] Из футера открываются страницы: «Как это работает», «Цены», «FAQ», «Оферта», «Политика конфиденциальности». На каждой есть текст-заглушка на обоих языках.
- [ ] Кнопка «Начать бесплатно» ведёт на страницу-заглушку воронки (сама воронка будет на этапе 2).
- [ ] В репозитории есть `README` с инструкцией «как запустить» и файл `.env.example`, где каждая настройка подписана по-русски.
- [ ] Превью-ссылка Vercel открывается.

## Этап 2. Тесты и подсчёт баллов

**Что появится:** можно пройти все 4 теста; баллы считаются автоматически.

**Как проверить:**
- [ ] «Начать бесплатно» открывает экран-развилку «Знаю свою цель / Не знаю, хочу разобраться».
- [ ] После выбора начинается Big Five: один вопрос на экран, 5 крупных кнопок с подписями, после нажатия сразу следующий вопрос.
- [ ] Есть прогресс-бар и кнопка «Назад». «Назад» возвращает к прошлому вопросу, выбранный ответ подсвечен.
- [ ] Порядок тестов: Big Five (60) → RIASEC (30) → Ценности (12) → Восприятие (8).
- [ ] Ответить на 10 вопросов, закрыть вкладку, открыть сайт снова: продолжение с 11-го вопроса.
- [ ] Выключить интернет на телефоне посреди теста, ответить, включить: ответы не пропали.
- [ ] Переключить язык посреди теста: вопросы и подписи кнопок меняются на другой язык, прогресс сохраняется.
- [ ] После последнего теста открыть `/dev/profile/<id сессии>` (ссылку даст Claude): видны проценты Big Five, код RIASEC, порядок ценностей, стиль восприятия, 16-тип.
- [ ] Проверка «на крайностях»: пройти всё, нажимая только «5». Результаты совпадают с ожидаемыми, которые Claude приведёт в отчёте.
- [ ] На боевом сайте (production) страница `/dev/...` не открывается.
- [ ] В отчёте Claude указано, сколько автотестов покрывают подсчёт (обратные пункты, ничьи, 16-тип, крайние значения).

## Этап 3. Контекстный опрос и профиль

**Что появится:** после тестов идёт опрос о ресурсах и цели; из всего собирается профиль.

**Как проверить:**
- [ ] После теста «Восприятие» начинается опрос: «О тебе» → «Ресурсы» → «Цель».
- [ ] Вопрос «Знаешь ли ты цель?» в опросе **не** задаётся повторно (он уже был на развилке).
- [ ] Путь «Знаю цель»: показывается блок «Подробнее о цели» (6 вопросов).
- [ ] Путь «Не знаю»: блока о цели нет вообще.
- [ ] Вопросы с несколькими ответами (языки, образ жизни) дают выбрать несколько вариантов.
- [ ] Возраст: нельзя ввести меньше 10 или больше 80.
- [ ] Необязательные вопросы (навыки, увлечения) можно пропустить.
- [ ] Обрыв посреди опроса: после перезагрузки продолжение с того же места.
- [ ] `/dev/profile/<id>` показывает итоговый профиль целиком, по структуре Приложения А §9 (Claude покажет в отчёте, как сверить).

## Этап 4. ИИ-тизер

**Что появится:** бесплатный результат после тестов. Работает и без ключа ИИ (тестовый режим).

**Как проверить (без ключа ИИ):**
- [ ] После опроса появляется экран «Анализируем твой профиль…» с анимацией.
- [ ] Затем открывается тизер: название типа, портрет, 2–3 сильные стороны, 2–3 направления одной фразой, крючок-сюрприз с замком, оглавление полного отчёта с замками.
- [ ] Вверху видна маленькая плашка «тестовый режим ИИ».
- [ ] В тизере нет плана действий, шагов, сумм, названий вузов.
- [ ] Перезагрузить страницу тизера: он не генерируется заново, показывается тот же.
- [ ] Попробовать сгенерировать тизер много раз подряд (Claude подскажет как): срабатывает лимит, показывается понятное сообщение.

**Как проверить (с ключом ИИ, когда владелец его даст):**
- [ ] Плашки «тестовый режим» нет.
- [ ] Тизер на RU написан по-русски, на UZ по-узбекски (латиницей).
- [ ] Портрет опирается на реальные баллы («судя по твоей высокой открытости…»), а не общие фразы.
- [ ] Ожидание не больше ~40 секунд.
- [ ] В отчёте Claude указано, сколько стоил один тизер (токены и примерная цена).

## Этап 5. Регистрация

**Что появится:** аккаунт по логину и паролю, код восстановления.

**Как проверить:**
- [ ] На тизере кнопка «Открыть полный отчёт» ведёт на регистрацию (до этого регистрацию нигде не просили).
- [ ] Регистрация спрашивает только логин и пароль. Нет полей ФИО, телефона, e-mail.
- [ ] После регистрации один раз показывается код восстановления с просьбой его сохранить.
- [ ] После регистрации тизер и все ответы остались (сессия привязалась к аккаунту).
- [ ] Выйти и войти снова: тизер на месте.
- [ ] Войти с другого браузера или телефона: тизер на месте.
- [ ] Ввести неправильный пароль много раз подряд: вход временно блокируется, показывается понятное сообщение.
- [ ] «Забыл пароль» → ввести логин и код восстановления → задать новый пароль → вход работает.
- [ ] Старый код восстановления после использования больше не работает (или выдаётся новый, как опишет Claude).

## Этап 6. Оплата-заглушка и полный отчёт

**Что появится:** выбор уровня, «тестовая» оплата, промокоды, полный отчёт онлайн.

**Как проверить:**
- [ ] Видны два уровня: «Маршрут» 29 000 сум и «Навигатор» 79 000 сум.
- [ ] Цены берутся из базы: Claude покажет, как поменять цену без правки кода, и после смены новая цена видна на сайте.
- [ ] Тестовая оплата проходит (только когда включён тестовый режим оплаты).
- [ ] Промокод на 100% открывает отчёт без оплаты. Промокод на скидку уменьшает сумму. Неверный промокод даёт понятное сообщение.
- [ ] После оплаты идёт экран генерации, затем открывается полный отчёт: портрет, цель, проверка цели на реальность, главный маршрут (варианты «здесь недорого / за рубежом / онлайн», «лёгкий / сложный путь»), 1–2 альтернативы, «что делать сейчас», дисклеймер.
- [ ] Все суммы и сроки в отчёте даны диапазонами с пометкой «ориентировочно».
- [ ] Отчёт удобно читать на телефоне.
- [ ] Имитация сбоя ИИ (Claude подскажет как): показывается понятное сообщение и кнопка «Сгенерировать заново», повторной оплаты не требуется.
- [ ] Выйти и войти снова: оплаченный отчёт доступен.
- [ ] Без оплаты открыть отчёт по прямой ссылке нельзя.
- [ ] В базе по оплате хранятся только id транзакции, сумма и статус (Claude подтвердит в отчёте).

## Этап 7. PDF и личный кабинет

**Что появится:** скачивание отчёта в PDF и личный кабинет.

**Как проверить:**
- [ ] На странице отчёта есть кнопка «Скачать PDF».
- [ ] PDF открывается на телефоне и компьютере, в нём есть логотип/название сервиса, все блоки отчёта.
- [ ] В PDF на RU кириллица нормальная, в PDF на UZ буквы `oʻ gʻ` нормальные.
- [ ] PDF можно распечатать: текст не обрезается по краям страницы.
- [ ] В кабинете список отчётов с датой и уровнем; каждый можно открыть и скачать снова.
- [ ] «Пройти заново» запускает новую сессию тестов, старые отчёты не пропадают.
- [ ] Смена пароля: старый пароль больше не подходит, новый подходит.
- [ ] Удаление аккаунта: после подтверждения войти с этим логином нельзя, отчёты недоступны.

## Этап 8. Админ-панель

**Что появится:** закрытая панель для управления сервисом.

**Как проверить:**
- [ ] Обычный пользователь не может открыть админку (видит «нет доступа»).
- [ ] Админ может: менять цены, создавать и выключать промокоды, смотреть отчёты.
- [ ] Суперадмин может то же + назначать и снимать роль админа.
- [ ] Промпты: можно отредактировать текст, сохраняется новая версия, можно вернуть старую версию.
- [ ] Для каждого уровня (тизер, «Маршрут», «Навигатор») можно выбрать модель ИИ.
- [ ] Аналитика воронки: таблица шагов «заход → старт теста → конец теста → тизер → регистрация → оплата → PDF» с числами. Пройти воронку самому: числа выросли на 1.
- [ ] Видна себестоимость ИИ на один отчёт.

## Этап 9. Реальная оплата

**Когда:** только после того, как владелец передаст данные мерчанта (Payme, потом Click и Uzum).

**Как проверить (для каждого шлюза):**
- [ ] Оплата в тестовой среде шлюза проходит, отчёт открывается сразу после оплаты.
- [ ] Отмена оплаты: понятное сообщение и возможность повторить.
- [ ] Неуспешная оплата (например, недостаточно средств в тестовой карте): доступ не открывается, сообщение понятное.
- [ ] Статус оплаты в админке совпадает со статусом в кабинете шлюза (сверка).
- [ ] Тестовый провайдер отключён, когда выключен тестовый режим оплаты.
- [ ] Вопрос с фискализацией (чеками) решён с владельцем и бухгалтером.

## Этап 10. Подготовка к запуску

**Как проверить:**
- [ ] Claude приложил отчёт о проверке безопасности (XSS, CSRF, инъекции, ограничения частоты запросов) со списком найденного и исправленного.
- [ ] Подключён мониторинг ошибок: Claude показывает тестовую ошибку, которая пришла в мониторинг.
- [ ] Сайт можно пройти с клавиатуры (Tab/Enter), текст контрастный и читаемый.
- [ ] Есть файл со всеми узбекскими текстами для вычитки носителем языка.
- [ ] Страницы оферты и политики заполнены заготовками, помечено, что должен проверить юрист.
- [ ] Есть чек-лист запуска (домен, переменные окружения, резервные копии базы, выключенный тестовый режим оплаты и ИИ), и все пункты отмечены.
