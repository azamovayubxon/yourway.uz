# Узбекский глоссарий yourway.uz

**Статус:** черновик. Названия предложены Claude и ждут проверки носителем языка (владельцем).

## Зачем этот файл

Из этого файла ИИ берёт узбекские названия типов, шкал и ценностей, когда пишет тизер (а позже и полный отчёт) на узбекском. Таблицы читает программа, поэтому:

- **меняйте только столбец «Узбекский»** (и при желании «Пояснение»);
- столбец «Код» не трогайте: по нему программа понимает, о чём строка;
- строки `<!-- section: ... -->` под заголовками тоже не трогайте;
- буквы oʻ и gʻ можно писать обычным апострофом (`o'`, `g'`), программа исправит сама.

Отсюда же берутся узбекские названия 16 типов, которые видит пользователь под названием своего типа в тизере.

Стиль узбекских текстов описан в [`uz-style.md`](uz-style.md).

## Запрещённые конструкции

Кальки и неестественные обороты. Если ИИ их напишет, ответ тоже генерируется заново. Конструкция ищется с начала слова: «A nuqta» ловит и «A nuqtadan».

<!-- section: forbidden_phrases -->

- A nuqta
- B nuqta
- kutilmagan yoʻnalishdagi ilk qadamlar
- halol oraliq
- reallikka tekshir
- sizning uchun
- qiymatli beruvchi
